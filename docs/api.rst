API reference
=============

Every name in ``porosity_fe.__all__`` is listed on this page; that list is
the package's public surface, and ``tests/test_docs.py`` fails if a name is
added to it without an entry here. Classes and functions link to a page
generated by ``sphinx.ext.autosummary`` from the numpydoc docstring.
Constants and type aliases are described inline.

Units throughout: stiffnesses and strengths in MPa, lengths in mm, ``Vp``
as a fraction in ``[0, 1]``. See :doc:`theory/index` for the models behind
each class.

.. py:data:: MATERIALS
   :type: dict[str, MaterialProperties]

   Built-in material presets keyed by name (for example
   ``MATERIALS["T800_epoxy"]``). Add a preset in
   ``porosity_fe/materials.py``.

.. py:data:: VOID_SHAPES
   :type: dict[str, tuple[float, float, float]]

   Named Eshelby shape radii ``(a1, a2, a3)``: ``'spherical'``
   ``(1, 1, 1)``, ``'cylindrical'`` ``(3, 1, 1)`` and ``'penny'``
   ``(3, 3, 0.3)``. Only the ratios matter.

.. py:data:: POROSITY_CONFIGS
   :type: dict[str, dict]

   The five named porosity configurations the sweeps compare
   (``'uniform_spherical'``, ``'uniform_cylindrical'``,
   ``'clustered_midplane'``, ``'clustered_surface'``,
   ``'interface_penny'``), each a dict of :class:`PorosityField` keyword
   arguments.

Type aliases
------------

``typing.Literal`` aliases for the string options the API accepts. Static
type checkers use them; at run time each function validates its own input.

.. py:data:: LoadingMode

   ``'compression' | 'tension' | 'shear' | 'ilss' | 'transverse_tension'``,
   the empirical loading modes.

.. py:data:: FELoadingMode

   ``'compression' | 'tension' | 'shear' | 'ilss'``, the loading modes
   :meth:`FESolver.solve` has boundary conditions for.

.. py:data:: FEFormulation

   ``'hex8' | 'hex8i'``, the element formulations :class:`FESolver` accepts
   (``formulation=``): the standard trilinear brick, or the default
   ``'hex8i'``, the brick with condensed incompatible modes that does not
   lock in bending.

.. py:data:: KnockdownModel

   ``'judd_wright' | 'power_law' | 'linear'``, the built-in empirical
   knockdown laws.

.. py:data:: Distribution

   ``'uniform' | 'clustered' | 'interface'``, the through-thickness porosity
   profiles.

.. py:data:: ClusterLocation

   ``'midplane' | 'surface' | 'quarter'``, where a ``'clustered'`` profile
   peaks.

.. py:data:: MeshFace

   ``'x_min' | 'x_max' | 'y_min' | 'y_max' | 'z_min' | 'z_max'``, the faces
   :meth:`CompositeMesh.nodes_on_face` accepts.
