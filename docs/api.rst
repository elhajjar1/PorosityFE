API reference
=============

Every name in ``porosity_fe.__all__`` is listed on this page; that list is
the package's public surface, and ``tests/test_docs.py`` fails if a name is
added to it without an entry here. Classes and functions link to a page
generated by ``sphinx.ext.autosummary`` from the numpydoc docstring.
Constants and type aliases are described inline.

Units throughout: stiffnesses and strengths in MPa, lengths in mm, ``Vp``
as a fraction in ``[0, 1]``. See :doc:`theory/index` for the models behind
each class.

   ``'interface_penny'``), each a dict of :class:`PorosityField` keyword
   arguments.

Delamination fracture mechanics
-------------------------------

Energy release rates along the front of an explicit
:class:`Delamination` by virtual crack closure, the mixed-mode toughness and
the critical load factor; :meth:`FESolver.solve` fills
:attr:`FieldResults.crack_front` with them. Energy release rates and
toughness in N/mm (1 N/mm = 1 kJ/m²). See :doc:`theory/delamination`.

.. autosummary::
   :toctree: api
   :nosignatures:

   CrackFront
   vcct_energy_release_rates
   fracture_load_factors
   critical_energy_release_rate

The FE knockdown of a porous, delaminated laminate is measured against the
laminate with neither defect; :func:`knockdown_decomposition` adds the
knockdowns of the porosity alone and of the delamination alone against the
same reference (two more solves, never run by :meth:`FESolver.solve`), so
the user sees which defect drives the loss.

.. autosummary::
   :toctree: api
   :nosignatures:

   knockdown_decomposition
   KnockdownDecomposition

The toughness at each front node is the material's, knocked down by the
porosity there: :class:`ToughnessKnockdown` selects the law
(``FESolver.solve(..., toughness_knockdown=...)``; the default exponential
law has uncalibrated placeholder coefficients), and
:func:`toughness_knockdown_factor` evaluates it without FE.

.. autosummary::
   :toctree: api
   :nosignatures:

   ToughnessKnockdown
   toughness_knockdown_factor

The toughness inputs scatter; :func:`fracture_load_factor_uncertainty`
(and :meth:`FieldResults.fracture_load_factor_uncertainty`) re-evaluates
the load factor of every front node for each draw of ``G_Ic``, ``G_IIc``,
``G_IIIc``, ``bk_eta`` and the law's ``b`` on the energy release rates of
the one solve, and returns a :class:`FractureLoadFactorBand`. Nothing
scatters unless named; see :doc:`theory/uncertainty`.

Interlaminar stresses and delamination onset
--------------------------------------------

The interlaminar traction recovered at the ply interfaces from a solve,
the stress-based onset criteria on it (Brewer-Lagace, Ye) with their load
factor, and O'Brien's closed-form energy release rate of a free-edge
delamination. Post-processing and lamination theory only: nothing the solve
computes changes. Stresses and strengths in MPa, energy release rates in
N/mm. See :doc:`theory/failure` (Interlaminar stresses and delamination
onset).

Type aliases
------------

``typing.Literal`` aliases for the string options the API accepts. Static
type checkers use them; at run time each function validates its own input.

.. py:data:: LoadingMode

   ``'compression' | 'tension' | 'shear' | 'ilss' | 'transverse_tension'``,
   the empirical loading modes.

.. py:data:: FELoadingMode

   ``'compression' | 'tension' | 'shear' | 'ilss' | 'flexure_3pt' |
   'flexure_4pt' | 'thermal'``, the loading modes :meth:`FESolver.solve`
   has boundary conditions for. ``'ilss'`` is the ASTM D2344 short-beam
   test and needs a specimen mesh from :meth:`CompositeMesh.for_ilss`.
   ``'flexure_3pt'`` and ``'flexure_4pt'``
   are three- and four-point bending on roller supports (ASTM D790 /
   D7264), best on a mesh from :meth:`CompositeMesh.for_flexure`.
   ``'thermal'`` is the free-standing cure residual-stress solve; it needs
   ``delta_T=`` and lamina CTEs (see the theory page on thermal and cure
   residual stress).

.. py:data:: FEFormulation

   ``'hex8' | 'hex8i'``, the element formulations :class:`FESolver` accepts
   (``formulation=``): the standard trilinear brick, or the default
   ``'hex8i'``, the brick with condensed incompatible modes that does not
   lock in bending.

.. py:data:: PorosityDegradation

   ``'isotropic' | 'directional'``, how :class:`FESolver`
   (``porosity_degradation=``) turns the local porosity into degraded ply
   stiffness and strengths: the default ``'isotropic'`` projects the
   Mori-Tanaka tensor of the porous matrix onto an isotropic one;
   ``'directional'`` keeps it transversely isotropic, so flat (penny) voids
   weaken the out-of-plane constants and the interlaminar strengths more
   (opt-in, uncalibrated; see the theory pages on micromechanics and
   failure). The two agree for spherical voids.

.. py:data:: KnockdownModel

   ``'judd_wright' | 'power_law' | 'linear'``, the built-in empirical
   knockdown laws.

.. py:data:: Distribution

   ``'uniform' | 'clustered' | 'interface'``, the through-thickness porosity
   profiles.

.. py:data:: ClusterLocation

   ``'midplane' | 'surface' | 'quarter'``, where a ``'clustered'`` profile
   peaks.

.. py:data:: MeshFace

   ``'x_min' | 'x_max' | 'y_min' | 'y_max' | 'z_min' | 'z_max'``, the faces
   :meth:`CompositeMesh.nodes_on_face` accepts.
